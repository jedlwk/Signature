**Yes, results come back in the same order as the frames you send.** The first result matches the first frame. The second matches the second, and so on.

Order is preserved for requests of up to 20 frames. Requests larger than 20 have not been tested, so 50 frames is outside what is verified.

So for 50 frames, send two requests of 20 and one of 10. Keep your own record of which frame ids went into which request. Then match results to frames by id as well as by position.
