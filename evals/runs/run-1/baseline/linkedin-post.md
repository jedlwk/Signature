Last week I ran a workshop for 30 HR leaders. None of them write code. By the end, each had built a small CV screening tool.

It took about an hour. People were surprised how quickly it came together.

But the question that took over the room wasn't "how do I build it?" It was "who checks the AI's work?"

Good question. Here is what we landed on:

1. A person makes the final call on every candidate. The tool ranks and summarizes. It does not reject.
2. Spot-check a sample each week. Read the CV, then read what the tool said about it.
3. Test it on CVs where you already know the right answer, and see where it gets them wrong.
4. Write down what the tool is allowed to look at. Anything that could stand in for age, gender or background stays out.

Building the tool turned out to be the easy part. The hard part is deciding who is accountable when it's wrong.

If you run hiring, who checks the AI's work in your team today?
